# Real local browser screenshots

Captured on 24 October 2026 from the isolated React → Spring Boot → MySQL demonstration.
Desktop captures use 1280 px; principal phone captures use 393 px. All required widths
320, 375, 393, 430, 768 and 1280 px were also checked for horizontal overflow.
These are screenshots of working components, not PDF mockups. Counts and status differ
between stages because the same real fictional journey progressed through review and collection.
All names, labels, emails and data are fictional; no active handoff code is shown.
Public demo passwords are masked. Some pages require vertical scrolling.

The sequence includes login, donor overview and all four donation steps, administrator
overview/review/accounts, NGO discovery/request/timeline, donor decision/schedule,
NGO handoff/completion and notifications. The review screenshots are an unsubmitted
second synthetic form used to show the final UI; the retained first walkthrough record
was actually submitted, approved and collected. The NGO request form shows an unsent
valid quantity; the original completed request is visible in the later timeline.
